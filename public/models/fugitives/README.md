# Quaternius fugitive prototype

This directory contains the selected characters used by the `fugitives` game
mode from
[Ultimate Animated Character Pack](https://quaternius.com/packs/ultimatedanimatedcharacter.html):

- `Worker_Male.fbx` and `Worker_Female.fbx`;
- `Doctor_Female_Young.fbx`;
- `Casual2_Male.fbx`;
- `Suit_Female.fbx`.

The source pack is published by Quaternius under CC0. Its original license is
preserved as `LICENSE.txt`. The selected FBX files contain their skeleton,
materials, and 17 animation clips; the files are otherwise unchanged.
